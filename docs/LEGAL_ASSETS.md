# EA game content, independent branding and asset policy

Not legal advice. Review current EA rules, the API provider's terms and Android/iOS app-store policies before distributing apps, promotional images or acquired data.

## Mandatory disclosure

Use in README and both About screens: **“This project is not endorsed by or affiliated with EA or its licensors.”** The name **Apex Companion** identifies an independent fan utility, not an EA-owned official tracker. Do not use EA/Apex Legends logos as app icons, imply sponsorship or copy Wingman UI compositions.

## Allowed subject to rights

- Original Apex Companion source, documentation, code icons and artwork created by contributors.
- Generic rank/map/progress visualization distinct from proprietary UI art.
- Remote source content only with provider permissions, attribution and lawful distribution.
- User-selected screenshots processed locally with consent; never commit private player screenshots to a public repo without appropriate rights.

## Excluded by default

EA game files, logos, data-mined graphics/audio, licensed fonts/skins/map art, nonpublic leaks, copied Wingman screenshots and asset packs. MIT license applies **only** to project-owned content and never automatically re-licenses EA/third-party material. Keep asset provenance ledger if graphics are added.

## Provider attribution

API docs identify attribution requirements (especially `/servers` and leaderboard sources if available). Keep source and last-refresh info visible for remote data on both Android and iOS. Verify current terms before enabling any public online feature.
