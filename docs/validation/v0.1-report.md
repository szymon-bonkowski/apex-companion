# v0.1 Maps implementation report — 2026-11-02

**Complete for authorized local developer use.** Android and shared map functionality are implemented and verified with both deterministic fixtures and real Apex Legends Status data. iOS integration/WidgetKit source is **Implemented — Not Verified**; all Apple checks are explicitly deferred to final stabilization under [ADR0007](../adr/0007-intermediate-platform-validation.md).

## Actual Android online/offline checks

Installed the debug APK, privately provisioned the developer key using the helper over ADB stdin, then checked:

1. Real synchronization produced a validated four-playlist cache with no error; UI displayed LIVE with actual current/next/countdown/source/last-sync.
2. Disabling emulator Wi-Fi and cellular and requesting refresh produced NETWORK failure. Cached schedules remained intact and UI displayed STALE.
3. Restoring connectivity and refreshing cleared the error and returned LIVE.
4. Selected Pubs, Ranked, Mixtape and Wildcard: actual current/next source values displayed; selections did not cause additional provider attempts.
5. Force-stopped and reopened the app: actual fresh cache survived and rendered without a duplicate upstream request.

Wi-Fi/cellular were restored. The emulator retains a private development credential in app data for this authorized local setup; it is not in any APK or widget/cache projection. The owner-only host credential remains outside the project. Remove device access at any time with the documented helper `--remove`. Neither regular public users nor release builds receive this path.

Real response bytes and screenshots are under the private host state directory outside the repository. Only structural evidence and synthetic screenshots are committed here; no actual provider map pool or assets were copied into fixtures.

## Privacy, legal and release gates

The supplied key was scanned against every ZIP entry of debug, unsigned release and test APKs: **absent from all three**. DEX inspection found the developer reader only in debug and the fail-closed factory only in release. Manifest inspection: debug is debuggable, release is not. Debug automatic backup is disabled; both backup formats exclude the private developer key. Provider/cache/widget records contain normalized global schedules and safe retry metadata, never auth or raw provider JSON. HTTP logging and credential-following redirects are disabled; raw exceptions are not exposed.

Merged APK permissions: INTERNET, FOREGROUND_SERVICE, ACCESS_NETWORK_STATE, WAKE_LOCK, RECEIVE_BOOT_COMPLETED and the app-private receiver permission; WorkManager contributes scheduling permissions. No photos/microphone/location/contacts permission, mandatory user account, analytics, ads, payment, game modification or proprietary EA asset was introduced. The provider developer verification requirement is not an app-user sign-in flow. Added dependencies are Apache-2.0 Ktor/Kotlinx/AndroidX; no comprehensive transitive vulnerability audit is claimed.

[Provider portal](https://apexlegendsapi.com/) documentation and private tests establish the observed developer contract, not a new redistribution right. Public release activation remains gated under ADR0002. No backend was deployed and no source art fetched.
