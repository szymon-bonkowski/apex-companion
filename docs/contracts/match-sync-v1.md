# Match sync v1 implementation contract

Private opt-in HTTPS mobile pull. Pairing is out-of-band explicit endpoint + SHA-256 DER certificate pin (64 lowercase hex) + random 32-byte bearer token (64 lowercase hex) + companionId + player identity. Pin mismatch MUST reject, even for self-signed certificates; no permissive TLS. Production targets private IPv4 LAN endpoints only. Listener starts only on explicit action, bind selected interface; no UPnP or public service. Token stored protected natively; never backup/log. TLS must precede Bearer authentication.

GET /v1/matches?after=<cursor> returns {"schemaVersion":1,"companionId":"UUID","cursor":1,"records":[...]}. Max 100 records/batch and 1 MiB response. Bearer token authentication, no redirects. Cursor is nonnegative durable global sequence of accepted records. Empty batch retains cursor; records and returned cursor committed atomically on mobile BEFORE acknowledgement. POST /v1/ack body {"cursor":1}; ack failure is safe to replay. Server retains records even after ack. Unpair revokes token. Client polls on foreground/manual sync only; no continuous background promise. No raw screenshots, secrets, provider data or arbitrary file endpoints.

Record JSON (all keys required; nullable values explicit):
```
{"schemaVersion":1,"id":"UUID-or-stable-event-id","identity":null,"mode":"UNKNOWN","map":null,"legend":null,"kills":null,"assists":null,"damage":null,"placement":null,"rpDelta":null,"timestampSeconds":1793700000,"timestampSource":"RESULT_OBSERVED","source":"WINDOWS_CAPTURE","quality":"REVIEW_REQUIRED","evidenceEventId":"companionUUID:eventUUID","parserVersion":"synthetic-v1","fieldConfidence":{},"revision":0}
```
identity is null or {"uid":"123","platform":"PC"}; platform is existing ApexPlatform PC/PLAYSTATION/XBOX/SWITCH. mode UNKNOWN/BATTLE_ROYALE/RANKED/MIXTAPE. source MANUAL/SCREENSHOT/WINDOWS_CAPTURE. quality REVIEW_REQUIRED/AUTO_ACCEPTED/USER_CONFIRMED. timestampSource RESULT_OBSERVED/USER_ENTERED. fieldConfidence keys mode/map/legend/kills/assists/damage/placement/rpDelta; finite doubles 0..1. No incidental OCR text. schemaVersion exactly1. IDs ASCII alphanumeric or -_.: max180. Strings max100 printable. kills/assists 0..100, damage0..100000, placement1..100, rpDelta -10000..10000 (defensive import bounds, not game rules). Manual requires USER_CONFIRMED; machine source requires evidenceEventId and parserVersion. Unknown nullable fields remain null. revision0 original; user edits increment revision and USER_CONFIRMED while retaining evidence IDs/source/parser. Sync never overwrites a local ID; identical replay is idempotent; edited local record with same immutable event identity is retained. Any conflicting original event is rejected atomically. Different IDs with same evidenceEventId are duplicate/conflict. Records for other paired identities must reject. No inferred session linking.
