# ADR 0005 — Independent identity and asset restrictions

**Status:** Accepted 2026-11-02.

**Context:** Apex Companion is an independent, free project inspired by players' companion needs, not an EA or Wingman licensee. Copyrighted logos, screenshot-derived UI and game artwork create rights/endorsement risk on both Android and iOS app listings.

**Decision:** Use original iconography and layout, explicit EA non-affiliation notice and source-specific provider attribution. Do not ship EA game assets, copied Wingman designs or data-mined art by default. MIT covers only original project content and code. The product name must not be presented as official.

**Alternatives:** Copying existing branded assets for initial polish carries unacceptable rights and distribution risks.

**Consequences:** Asset creation is extra work; store listing and trademark risks require review independently of code correctness.

**Validation:** Asset inventory/provenance, README/About non-affiliation, current EA/IP policy and store listing checks for both Android and iOS before release.
