# Security policy

Please report suspected vulnerabilities privately to the project maintainer via the repository's private vulnerability reporting channel when configured; avoid public disclosure of sensitive exploit details or player data. If no private reporting channel is configured, ask the maintainer for a safe private contact method first rather than publishing secrets in an issue.

Scope includes Android app, iOS app, Xcode WidgetKit extension/App Group, locally exported data, native widget actions, provider integration, optional gateway, signing and source dependencies. This documentation-only starter has **no built app, released binaries or operational backend**.

Never report real player UID, source API token, private profile data, raw screenshot or credentials in public issues. A reproducible synthetic fixture is preferred. The project does not manipulate Apex Legends, access anti-cheat, use unauthorized game APIs or evade source quotas. See [SECURITY_PRIVACY.md](docs/SECURITY_PRIVACY.md).
