# Code of conduct

Apex Companion welcomes constructive participation from players and developers across Android and iOS. Treat contributors respectfully regardless of experience, background or gaming skill. Criticize work and evidence, not people. Harassment, hate speech, threats, spam, doxxing and unsolicited sharing of another player's data are unacceptable.

For conduct concerns, use an available private maintainer contact route. Do not post personal data or API credentials publicly. Project contributors are also expected to respect source licensing and the independent EA non-affiliation policy.
